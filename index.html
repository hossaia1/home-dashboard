Text size
Applies instantly. The screen is a fixed size, so larger text shows fewer forecast hours and calendar entries rather than spilling over the edge.
Prayer calculation method
At Helsinki's latitude the sun never reaches 18° below the horizon in summer, so angle-based methods (MWL, ISNA, Egyptian) produce badly wrong Fajr and Isha. Moonsighting Committee handles high latitudes correctly.

Fine-tune (minutes)

Night mode (burn-in protection)
Dim this many minutes after Isha, and again after you wake it
Stays dark until Fajr. Tap anywhere to wake it; it dims again on its own after the delay above, so it can't be left bright overnight by accident.
Adhan
Plays a preview. Tap the Adhan on/off button on the dashboard to toggle.
Own recording? Put adhan.mp3 next to index.html — it overrides the online one. Add adhan-fajr.mp3 for the Fajr call. Replacing either file is picked up on the next reload; it is cached so the adhan still plays with no internet.
Calendar bridge URL (recommended)
Apps Script web app — gives live reads and lets you add events from the dashboard. Setup steps are in apps-script/Code.gs. Keep this URL private.
Tip: while developing, paste the /dev URL instead — it always runs the latest saved script, so no redeploy. Use /exec on the tablet.
Calendar — iCal URL (fallback)
